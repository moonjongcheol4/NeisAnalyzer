# 나이스 성적 분석

나이스(NEIS)에서 내려받은 성적 엑셀 파일들을 한꺼번에 끌어다 놓으면,
학생별 최종 점수·등수·성취도부터 문항 분석(정답률·변별도·신뢰도)까지 담긴
**결과 엑셀 파일(시트 17개 안팎)** 을 자동으로 만들어 주는 Windows 프로그램입니다.

- 설치 없이 `나이스성적분석.exe` 파일 하나로 실행됩니다 (Windows 10 / 11).
- 중학교 반 단위 파일과 고등학교(고교학점제) 강의실 단위 파일을 모두 처리합니다.
- **인터넷에 연결하지 않으며, 학생 자료는 컴퓨터 밖으로 나가지 않습니다.**
- 결과의 모든 지표에 "무엇인지, 높을수록 좋은지, 어떻게 읽는지" 설명이 함께 들어갑니다.

## 내려받기

[Releases](../../releases) 페이지에서 최신 버전의 `나이스성적분석.exe`를 내려받아 아무 폴더에나 두고 실행하세요.

처음 실행할 때 Windows가 "알 수 없는 앱" 경고를 띄우면 **[추가 정보] → [실행]** 을 누르면 됩니다.
(개인이 만든 프로그램이라 뜨는 정상적인 경고입니다.)

## 사용법

### 1. 나이스에서 파일 받기

나이스에서 아래 세 가지를 **엑셀로 저장**합니다. 파일 이름(`download-숫자.xlsx`)은 바꾸지 않아도 됩니다.
프로그램이 파일 내용을 읽어 종류와 반을 스스로 알아냅니다.

| 번호 | 나이스 경로 | 비고 |
|---|---|---|
| ① | 교과담임 → 정기시험조회/통계 → 정기시험조회 → **[교과목별학생답정오표(학급별)]** | 반 수만큼 저장 |
| ② | 교과담임 → 정기시험조회/통계 → 정기시험조회 → **[교과목별일람표조회(전체학급)]** | 필요시 검토(검산)용, 없어도 됨 |
| ③ | 교과담임 → 수행평가조회/통계 → 수행평가조회 → **[강의실별일람표조회-전체영역(학급별)]** | 반 수만큼 저장 |

중간고사와 기말고사가 모두 있는 학기라면 두 고사의 ① 파일을 함께 넣으면 됩니다.

### 2. 프로그램에 넣기

1. `나이스성적분석.exe`를 실행합니다.
2. 받은 파일들(또는 파일이 든 폴더)을 파란 상자에 **끌어다 놓습니다**. [파일 선택...] 버튼으로 골라도 됩니다.
3. 목록에 "정오표 - 3학년 1반 …", "수행평가 - 3학년 1반 …"처럼 ✔ 표시로 뜨는지 확인합니다.
   빠진 반, 중복, 학년·학기가 섞인 파일은 아래 "확인이 필요한 사항"에 경고로 나옵니다.

### 3. 설정 확인

오른쪽 설정은 파일에서 읽은 값으로 자동으로 채워집니다. 필요하면 고치세요.

- **수행평가 영역별 만점·반영 비율**: 수행 파일의 영역 제목에서 읽어 옵니다.
- **지필평가 반영 비율**: 고사가 하나면 `100 − 수행 비율`, 둘이면 나누어 입력합니다. 합이 100%가 아니면 빨간 글씨로 알려 줍니다.
- **성취도 기준**: 기본 A 90 / B 80 / C 70 / D 60 이상, 그 미만 E.
- **반올림 방식**: 기본은 나이스와 같은 소수 둘째 자리이며, 성취도는 최종 점수를 정수로 반올림한 값(학교생활기록부 원점수 방식)으로 판정합니다. 학교 학업성적관리규정에 맞게 바꿀 수 있습니다.
- **성취도 경계 표시 범위**: 기본 ±1점.

### 4. 분석 시작

[▶ 분석 시작] → 저장 위치 선택 → 몇 초 뒤 완료. [결과 파일 열기]로 엑셀을 엽니다.
②번 일람표를 넣었다면 상태 줄에 "검산: 나이스 일람표와 모두 일치 ✔"가 나와야 정상입니다.

## 결과 엑셀의 시트

| 시트 | 내용 |
|---|---|
| 0.읽는 법 | 모든 지표의 뜻·범위·방향·읽는 법 (처음 보는 분은 여기부터) |
| 1.요약 | 응시 인원, 평균·중앙값·표준편차, 성취도 분포, 반별 평균 순위, 주요 지표 해석, 자동 요약 문장 |
| 2.학생별 성적 | 반·번호·이름, 수행 영역별 점수, 지필 원점수·환산 점수, 최종 점수, 학년·반 등수, 성취도, 경계 표시 |
| 3.등수표 | 최종 점수 순 |
| 4.성취도 분석 | 학년·반별 A~E 인원·비율 + 그래프, 성취도별 인원·평균·표준편차(교육과정평가원 성취도분석표 구성), 경계 학생 목록 |
| 5.반별 비교 | 반별 평균·중앙값·표준편차·최고·최저, 수행·지필 평균 + 그래프 |
| 6.점수 분포 | 10점 구간별 인원 히스토그램 (학년·반별) |
| 7.수행평가 분석 | 영역별 평균, 만점자·최저점 비율, 반별 영역 평균, 점수별 인원 |
| 8.문항 분석 | 문항별 정답률·오답률·무응답률, 난이도, 변별도, 문항-총점 상관, 매력적 오답, 종합 판정, KR-20 신뢰도 |
| 8-2.답지 반응 | 문항별 ①~⑤ 선택 비율 (정답 파란색, 매력적 오답 빨간색) |
| 8-3.반별 문항 | 반별 문항 정답률 비교 (학년보다 15%p 이상 낮으면 빨간색) |
| 8-4.성취도별 문항 | 성취도 A~E 집단별 문항 정답률, 낮은 집단이 높은 집단보다 15%p 이상 많이 맞힌 "수준 역전" 문항 표시 |
| 9.수행 vs 지필 | 산점도, 상관계수, 두 평가 차이가 큰 학생 |
| 10.관심 학생 | 성취도 E, 경계, 무표기 많음, 수행·지필 차이 큼, 면제·결시 학생과 사유 |
| 11.점수 변화 | (중간·기말이 모두 있을 때) 점수 변화, 크게 오르거나 내린 학생 |
| 12.개인별 결과표 | 학생 한 명당 한 블록 (점수·등수·성취도·틀린 문항) — 상담·인쇄용 |
| 13.검산 | 정오표로 계산한 반별 응시생수·총점·평균과 나이스 일람표 비교 |
| 14.분석 기준 | 사용한 비율·기준·반올림 방식, 제외한 학생과 이유, 사용한 파일 |

## 처리 규칙

- 학생은 **반 + 번호**로 맞추고, 이름·학번이 파일마다 다르면 경고합니다.
- 수행 전체 면제, 지필 결시·면제 학생은 평균·등수·성취도 분포에서 빼고 "관심 학생" 시트에 사유와 함께 표시합니다.
- 일부 영역만 면제인 학생은 포함하되 표시합니다 (합계는 나이스 값 그대로).
- 번호가 비는 반, 반마다 다른 인원, 전입생(학번 형식이 다름)을 그대로 처리합니다.
- 문항 수·배점·선택형/서답형 구성은 파일에서 읽으므로 학년·과목에 관계없이 쓸 수 있습니다. 서답형은 문항별 자료가 없어 점수 합계로만 처리합니다.
- 총점 열이 "영역총점"이든 "과목총점"이든, 학생 줄에서 학번과 반/번호의 순서가 어떻든 읽습니다. 고사 이름은 "기말고사", "1차 시험" 같은 형식을 모두 인식합니다.
- **고등학교(고교학점제)**: 파일이 "강의실" 단위이거나 한 파일에 여러 반 학생이 섞여 있으면 자동으로 강의실 모드가 됩니다. 반 대신 강의실(수업 집단) 단위로 비교하고, 학생은 행정반/번호로 식별해 "강의실 | 반 | 번호 | 이름"으로 보여 줍니다. 고등학교 일람표(검산용)는 강의실 단위 열로 되어 있다고 가정합니다.
- PDF나 옛 .xls 파일은 읽지 않습니다. 나이스 저장 화면에서 **XLS data**(.xlsx)를 고르세요.
- 등수는 동점이면 같은 등수, 다음 등수는 건너뜁니다 (1, 1, 3).
- 표준편차는 모집단 방식(N으로 나눔, 교육과정평가원 분석 프로그램과 같음)입니다. 엑셀 STDEV.S보다 조금 작게 나옵니다.
- 화면은 Windows의 "텍스트 크기 125%·150%" 설정과 작은 노트북 화면에서도 글자가 겹치지 않게 맞춰집니다.

## 개발자용

```powershell
.\build.ps1            # dist\나이스성적분석.exe 생성 (.NET SDK 필요)
.\tests\run-smoke.ps1  # 가짜 이름 예시 파일로 자동 시험
```

- C# WinForms, .NET Framework 4.8. 엑셀 처리는 [EPPlus 4.5.3.3](https://github.com/JanKallman/EPPlus) (LGPL-3.0)을 exe 안에 포함했습니다. 자세한 내용은 `ThirdPartyNotices.txt`.
- `tests/sample`, `tests/sample-midterm`은 `tools/make_sample.py`로 만든 **가짜 이름** 예시 파일입니다. 실제 학생 자료는 저장소에 넣지 마세요 (`.gitignore`로 `*.xlsx`를 막아 두었습니다).
- 명령줄 모드: `나이스성적분석.exe --cli <폴더 또는 파일들> --out 결과.xlsx`
