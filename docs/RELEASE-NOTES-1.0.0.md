# 나이스 성적 분석 1.0.0 (2026-11-13)

첫 공개 버전입니다.

- 나이스 정오표(반별)·수행평가 일람표(반별)·교과목별 일람표(검산용)를 끌어다 놓으면 결과 엑셀(시트 16개)을 만듭니다.
- 학생별 최종 점수·학년/반 등수·성취도·경계 표시, 반별 비교, 점수 분포, 수행평가 분석
- 문항 분석: 정답률·변별도·문항-총점 상관·매력적 오답·답지 반응 분포·반별 문항 정답률·KR-20 신뢰도
- 수행 vs 지필 비교, 관심 학생, 중간→기말 변화(두 고사가 있을 때), 개인별 결과표, 검산, 분석 기준 안내
- 모든 지표에 뜻·범위·방향·읽는 법 설명 포함 ("0.읽는 법" 시트 + 각 시트 아래)
- 인터넷 연결 없이 동작, 학생 자료 외부 전송 없음
