# 나이스 성적 분석 1.1.0 (2026-11-13)

## 고친 것
- **다른 컴퓨터에서 글자가 겹치거나 줄바꿈이 이상하던 문제 수정.** Windows 디스플레이 설정의 텍스트 크기(125%·150% 등)에 맞춰 단추·표·줄 높이를 함께 키우고, 제목 줄은 글자 크기에 따라 높이가 정해지도록 바꿨습니다. 작은 화면(노트북)에서는 창이 최대화되고 설정 부분은 스크롤됩니다. 맑은 고딕이 없는 컴퓨터에서는 시스템 기본 글꼴을 씁니다.

## 새로 넣은 것
- **8-4.성취도별 문항** 시트: 성취도 A~E 집단별 문항 정답률. 낮은 집단이 높은 집단보다 15%p 이상 많이 맞힌 문항을 "수준 역전"으로 표시해 정답 오류·찍기 쉬운 문항을 찾습니다(두 집단 모두 5명 이상일 때).
- **4.성취도 분석** 시트에 성취도별 인원·비율·최종 점수 평균·표준편차·최저·최고·수행 평균·지필 평균 표 추가(교육과정평가원 성취도분석표와 같은 구성).
