# 나이스 성적 분석 1.1.1 (2026-11-13)

다른 학교 선생님의 정오표가 "읽기 실패"로 뜨던 문제를 고쳤습니다.

## 고친 것
- **총점 열 머리글이 "과목총점"인 정오표**(영역을 두지 않은 과목)를 읽지 못하던 문제 수정. "영역총점"·"과목총점" 모두 읽습니다.
- **학생 줄에서 학번이 앞에, 반/번호가 뒤에 오는 정오표·수행평가 일람표**를 학생 0명으로 읽던 문제 수정. 순서를 파일에서 알아서 판단합니다.
- 고사 이름에 "고사"가 들어가지 않는 시험("1차 시험", "2차 지필평가" 등)도 고사 이름으로 인식합니다. 이전에는 이 이름이 과목으로 잘못 들어갔습니다.
- PDF 등 엑셀이 아닌 파일을 넣으면 영어 오류 대신 "엑셀(.xlsx) 파일이 아니라서 읽지 않습니다"라고 우리말로 알려 줍니다. 옛 .xls 형식은 'XLS data'로 다시 저장하라고 안내합니다.
- 자동 시험에 위 형식(과목총점 + 학번 먼저)의 가짜 자료 세트를 추가했습니다.
