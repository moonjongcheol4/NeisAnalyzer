# 나이스 성적 분석 1.2.0 (2026-11-16)

고등학교(고교학점제) 파일을 지원합니다.

## 새로 넣은 것: 고교학점제 강의실 모드
- 고등학교 나이스 정오표·수행평가 일람표는 행정반이 아니라 **강의실(수업 집단)** 단위로 나오고, 한 강의실에 여러 반 학생이 섞여 있습니다. 이전 버전은 이를 "5반 정오표 안에 6반 학생이 있습니다"라는 경고로 띄우고 반별 비교를 엉뚱하게 했습니다.
- 이제 파일 머리말이 "강의실"이거나 **한 파일에 여러 반 학생이 섞여 있으면 자동으로 강의실 모드**가 됩니다. 머리말에 "강의실"이라는 말이 없어도 됩니다.
- 강의실 모드에서는 반 대신 **강의실 단위로 비교**합니다(강의실별 비교, 강의실별 문항 정답률, 강의실 등수, 점수 분포, 검산). 학생은 **행정반/번호로 식별**하고, 학생 표마다 "강의실 | 반 | 번호 | 이름" 네 열로 보여 줍니다. 개인별 결과표에도 "1반 1번 이름 (3강의실)"처럼 적습니다.
- 중학교 파일은 이전과 완전히 같게 처리됩니다(기존 가짜 자료 결과가 바뀌지 않는 것을 확인했습니다).
- 자동 시험에 고교학점제형 가짜 자료 세트(`tests/sample-lecture`, 생성기 `--lecture`)를 추가했습니다.

## 알아 둘 점
- 고등학교의 교과목별 일람표(검산용)는 실제 파일을 보지 못해 **강의실 단위 열로 되어 있다고 가정**했습니다. 행정반 기준이면 검산이 "불일치"로 나올 수 있으며, 그 경우 일람표는 빼고 쓰면 됩니다. 고등학교 일람표·수행평가 파일을 보내 주시면 맞추겠습니다.
- 강의실 모드에서는 일람표와 학생별 점수 대조를 하지 않습니다(번호가 여러 반에 걸쳐 겹치기 때문). 강의실별 인원·총점·평균 검산은 합니다.
