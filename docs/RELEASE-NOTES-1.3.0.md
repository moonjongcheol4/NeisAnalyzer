# 나이스 성적 분석 1.3.0 (2026-11-16)

## 새로 넣은 것: 문항정보표(선택 사항)로 예상 난이도 vs 실제 난이도 비교
- 나이스 **교과담임 → 정기시험 → 문항정보표관리 → [문항정보표]** 를 엑셀로 저장해 함께 넣으면, 출제 교사가 시험 전에 적은 **예상 난이도(어려움·보통·쉬움)** 를 시험 뒤 정답률로 정한 **실제 난이도**와 문항별로 비교합니다. 넣지 않아도 이전과 똑같이 동작합니다.
- **8.문항 분석** 시트의 "난이도" 열 옆에 "예상 난이도", "예상과 비교"(예상대로 / 예상보다 어려웠음 / 예상보다 쉬웠음, 두 단계 차이는 빨간색·한 단계 차이는 노란색), "내용영역", "성취기준" 열이 붙고, 표 아래에 예상×실제 난이도 교차표가 추가됩니다. 표 위에는 예상보다 어려웠던·쉬웠던 문항 번호를 한 줄로 요약합니다.
- **1.요약**의 주요 지표에 "예상 난이도와 다른 문항 수", 자동 요약에 비교 문장이 들어갑니다. "0.읽는 법"에 예상 난이도 읽는 법을 추가했습니다.
- 중간고사·기말고사 문항정보표를 둘 다 넣으면 고사 이름("중간"·"기말"·"1차" 등)으로 짝을 맞춰 고사별 시트에 각각 비교합니다. 짝이 맞지 않는 문항정보표는 경고만 내고 건너뜁니다.
- 문항정보표의 정답·배점이 정오표와 다르면(다른 시험의 정보표이거나 정답 정정이 있었을 때) 경고로 알려 줍니다.
- 화면의 나이스 경로 안내에 ④ 문항정보표 줄을 "(선택 사항)"으로 추가했습니다.
- 자동 시험의 중간·기말 세트에 가짜 문항정보표 2개를 추가했습니다(생성기 `--iteminfo`).
